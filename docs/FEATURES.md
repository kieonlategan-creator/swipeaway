# SwipeAway Features

## Core

- **Swipe discovery feed** — Tinder-style cards for browsing destinations
- **Destination cards** — hero photo, country, estimated cost, tags
- **Swipe mechanics** — right to save, left to skip, up to book
- **Budget filtering** — set a price range and only see destinations that fit
- **Search & filters** — filter by continent, trip type, travel dates, duration
- **Smart recommendations** — personalised suggestions based on swipe history

## Booking

- **Flight API integration** — real-time pricing via Amadeus / Skyscanner / Kiwi
- **Hotel API integration** — listings and rates via Booking.com / Amadeus
- **Flight results screen** — compare airlines, prices, times, stops
- **Hotel results screen** — compare hotels by price, stars, review score
- **Price drop alerts** — push notifications when wishlisted routes get cheaper
- **In-app booking** — book flights and hotels without leaving the app (Phase 3)

## User

- **Account login** — email/password, Google OAuth, Apple Sign In
- **User profile** — avatar, display name, home airport, currency, preferences
- **Wishlist** — save destinations with notes and travel dates
- **Saved trips** — planned itineraries combining destination + flights + hotels
- **Travel stats** — countries swiped, wishlisted, visited
- **Onboarding flow** — set budget, interests, and home airport on first launch

## Social

- **Share wishlists** — send destination lists to friends
- **Group trips** — invite friends, vote on destinations together
- **Travel stories** — short-form photo/video content from travellers (Phase 3)

## Content

- **Destination images** — high-quality photos via Unsplash / Pexels
- **Weather data** — current conditions at each destination via OpenWeather
- **Points of interest** — nearby attractions via Google Places
- **Reviews & ratings** — user-generated destination reviews (Phase 3)

## Monetisation

- **Freemium model** — 50 free swipes/day, Pro unlocks unlimited
- **SwipeAway Pro** — £4.99/mo for unlimited swipes, price alerts, AI trip planning
- **Affiliate links** — earn commission on flight/hotel bookings
- **Sponsored destinations** — promoted cards from tourism boards and airlines
