Architecture

Frontend

  • React Native 0.81 + Expo 54
  • TypeScript + Expo Router
  • Zustand (state) + TanStack Query (data)
  • Reanimated + Gesture Handler

Backend (Planned)

  • Node.js + Express
  • PostgreSQL + Prisma ORM
  • Redis caching
  • JWT + OAuth 2.0 auth

Third-Party APIs

  • Amadeus / Skyscanner — flights
  • Booking.com — hotels
  • Unsplash / Pexels — images
  • OpenWeather — weather
  • Stripe — payments

Infrastructure

  • Expo EAS — builds
  • Vercel / Railway — hosting
  • Sentry — error tracking
  • PostHog — analytics
Features

Core

  • Swipe discovery feed — Tinder-style cards
  • Destination cards — photo, cost, tags
  • Swipe mechanics — right save, left skip, up book
  • Budget filtering — price range filter
  • Search & filters — continent, trip type, dates
  • Smart recommendations — from swipe history

Booking

  • Flight API — Amadeus / Skyscanner / Kiwi
  • Hotel API — Booking.com / Amadeus
  • Price drop alerts — push notifications
  • In-app booking — Phase 3

User

  • Account login — email, Google, Apple
  • Wishlist — save destinations
  • Saved trips — planned itineraries
  • Travel stats — swiped, wishlisted, visited
